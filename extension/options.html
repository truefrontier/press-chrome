Press Chrome

Read-only agent bridge. No chrome.debugger. Token from chtabs init.

How to use

  1. Run chtabs init then chtabs serve in a terminal.
  2. Paste the token here and Save.
  3. Click the toolbar icon on a tab to Share it (badge = shared count).
  4. Agents: chtabs list, chtabs active, chtabs read <id>, chtabs history.

Chrome profile: load this unpacked extension in your Default daily profile (kirchner.kevin@gmail.com).
